## 🛠️ Estrutura do Projeto
Plaintext:

* **Camada Modular**: Organização profissional com separação entre Interface (`app.py`) e Lógica de API (`engine.py`).
* **Agente Plan**: Focado em arquitetura de sistemas e planejamento.
* **Agente Agent**: Focado em implementação e geração de código funcional.
* **Agente Study**: Especialista em explicação didática de conceitos técnicos.
* **Agente Ask**: Suporte técnico direto para dúvidas de terminal e ambiente.

``` 
ai-copilot-pro/
├── src/                # Código fonte do projeto
│   ├── app.py          # Interface Gráfica (Streamlit)
│   ├── engine.py       # Lógica de conexão com a API
│   └── main.py         # Versão legada para Terminal
├── .env                # Sua chave de API (Criado manualmente)
├── .gitignore          # Proteção para não enviar sua chave ao GitHub
└── README.md           # Este manual de uso
``` 

## 🚀 Como Executar e Testar os Agentes

Inicie a interface gráfica atravé do link:


Para validar se o sistema está funcionando e mantendo o contexto, siga esta sequência de testes na barra lateral, ou "INSIRA O PROMPT DA SUA PREFERÊNCIA, desde que seja voltado para o contexto de desenvlvimento*, pois o motor de IA sinconizado é específico para PROGRAMAÇÃO".

    Exemplos de Teste - Agente Plan (O Arquiteto):

        Ação: Selecione Plan.

        Prompt: "Planeje a estrutura de pastas para um catálogo de livros em Python."

        Resultado esperado: Uma lista organizada de pastas e sugestões técnicas.

    Teste - Agente Agent (O Executor):

        Ação: Sem limpar o chat, mude para Agent.

        Prompt: "Com base no plano anterior, escreva o código do arquivo principal."

        Resultado esperado: O agente deve gerar o código baseando-se no que foi discutido com o Arquiteto.

    Teste - Agente Study (O Professor):

        Ação: Mude para Study.

        Prompt: "Explique os conceitos de banco de dados usados nesse código."

        Resultado esperado: Uma explicação didática sobre as tecnologias implementadas pelo Agente anterior.

    Teste - Agente Ask (O Suporte):

        Ação: Mude para Ask.

        Prompt: "Como eu rodo este código no meu terminal Linux?"

        Resultado esperado: Comandos diretos e suporte técnico rápido.
